Reporting a Vulnerability
Please do not open public GitHub issues for security vulnerabilities.

I take the security of this project seriously. If you believe you have found a security vulnerability, please use the Private Vulnerability Reporting feature on GitHub.



How to report:
On GitHub.com, navigate to the main page of the repository.

Under the repository name, click Security.

In the left sidebar, under "Reporting", click Vulnerability reporting.

Click Report a vulnerability to open the advisory form.

Fill out the details (including a proof of concept if possible) and click Submit report.



Developer's Commitment
Acknowledgement: I will acknowledge receipt of your report within 48 hours.

Investigation: I will investigate and provide a status update within 7 days.

Resolution: Once a fix is verified, I will coordinate a release and provide credit to the reporter (if desired).
